# portfolio-site

Personal portfolio for Max Norris. Built with Vite, React, TypeScript and React Router.

## Routes

- `/` — Home
- `/resume` — Resume
- `/satellite-conjunction-screening` — Satellite conjunction screening project

## Development

```sh
npm install
npm run dev      # local dev server (also serves api/ functions)
npm run lint     # eslint
npm test         # node:test unit tests in tests/
npm run build    # type-check (app, vite config, api) + production build to dist/
npm run preview  # serve the production build
```

## Structure

- `src/styles/tokens.css` — design tokens (colors, fonts). All colors are referenced through these variables.
- `src/data/satelliteTool.ts` — static facts about the satellite project (repo link, tech stack).
- `api/satellite/summary.ts` — Vercel function, `GET /api/satellite/summary?limit=N` (default 25, max 200; add `&date=YYYY-MM-DD` for a retained day's report). Reads the screening pipeline's full report (`reports/current.json`, ~78 MB) from the public Tigris bucket server-side and returns risk-level counts plus the top-N conjunctions, ranked by risk tier then miss distance (~11 KB at the default limit). Cached by Vercel's CDN for an hour. The satellite page and the home page's featured stats read from it via `src/hooks/useSatelliteSummary.ts`.
- `src/components/SatelliteGlobe.tsx` + `src/globe/` — the 3D globe on the satellite page, lazy-loaded so three.js and satellite.js (~150 KB gzipped) stay out of the main bundle. It fetches `objects/current.json` (and retained `objects/<date>.json.gz` snapshots for past days, listed in `history/index.json`) straight from the public bucket, whose CORS rule allows the production origin and `localhost:5173`/`4173`. Every object is propagated with SGP4 in its inertial frame, a tenth of the catalog per frame. The Earth mesh is rotated by GMST so the texture lines up with real geography (`tests/globe.test.ts` checks this). Includes near-miss replay from the table (both objects ringed, with a labelled miss line), point colouring by type, owner or flat with per-category show/hide, curated name filters (constellations and the two historical debris events), ISS/Tiangong station views that follow the station, click-to-inspect any point with its nearest neighbour, a sourced collision-history panel, a time slider (retained days back, ~24 h forward, Live at 1/10/50x), and a Globe | Sky toggle: the Sky view shows every tracked object above a chosen location's horizon on a first-person dome (browser geolocation, or a place looked up with OpenStreetMap Nominatim; the location stays in the browser). Sky geometry lives in `src/globe/sky.ts` and is checked against satellite.js look angles in `tests/sky.test.ts`. The globe is shaded day/night by the Sun's position at the displayed time (`src/globe/sun.ts`, satellite.js's low-precision solar formula, checked against astronomy-engine in tests only), with a soft twilight band and city lights on the night side; a Day/night switch turns it off. Earth textures, 2048×1024 in `public/textures/`: NASA Visible Earth Blue Marble (day) and NASA Earth Observatory Black Marble 2016 city lights (night).
- `src/globe/skydim.ts` — the satellite view dims the sky when it looks at the Earth, as a camera exposed for the sunlit Earth would: the Milky Way glow and the stars are multiplied by factors that depend on how much of the view is Earth (the fraction of a cap of the view's field of view that falls inside the Earth's disc, so narrow and wide fields both behave) and on whether the point below the satellite is sunlit (the shipped defaults, tuned by hand, leave daylight undimmed, 1.0, and take glow and stars to ×0.19 when the Earth fills the view over the night side, blended through twilight), eased over about 400 ms. Only brightness changes (not which stars load, show or can be picked); the Sun, Moon, planets, constellations, the Earth and the selection are never dimmed. Retune from the console with `__globe.skyDim` (`?debug=1` exposes `__globe` on the live site and adds a "sky dim" line to the overlay).
- `src/globe/glowtuning.ts` — the Milky Way glow's look (built from the Gaia glow atlas, `src/globe/glow.ts` and `glowlayer.ts`) and the stars' tuned look, as tuned by hand with the debug panel: glow gain 0.20, saturation 0.60, gamma 1.35 and no blur (with a blur of 0 the background blur work is skipped; the map is the atlas interpolated between pixel centres); stars at brightness ×1.10 and point size ×1.00, with 3.5 magnitudes added to the limiting magnitude at fields wider than 15 degrees (fading to nothing by 5), which shows far more of the 118,217 Hipparcos stars at wide views. The glow gain multiplies the narrow-field and Earth-in-view dimming. Retune from the console with `__globe.glowGain`, `glowSaturation`, `glowGamma`, `glowBlur`, `starBrightness`, `starSize` and `wideLimitOffset` (a changed blur rebuilds the map in the background); `?debug=1` shows the current values.
- `?debug=1` also adds a collapsible **Sky tuning** panel in the Satellite view (`src/components/SkyTuningPanel.tsx`, logic in `src/globe/skytuning.ts`; its own lazy chunks, never fetched without `?debug=1`): sliders for the glow (gain, saturation, gamma, blur), the Earth-in-view dimming (glow and stars, sunlit and night) and the stars (brightness, point size, and a wide-field limiting-magnitude offset that fades out between 15 and 5 degrees), with Reset to defaults, Original look and Copy settings (JSON). The sliders write the same engine settings the console hooks do, and the values are remembered in `localStorage` in debug mode only.
- The satellite tool's page layout (`src/pages/SatelliteTool.tsx` and `.css`, `src/components/SatelliteGlobe.css`, `src/globe/pagelayout.ts`, `src/globe/credits.ts`): a compact header, then the tool (the Globe | Sky | Satellite switch and the controls in a left column of `clamp(300px, 24vw, 420px)` with its own scrolling, the map beside it, the clock row attached under it, and a short credits line), then the Conjunction screening, For context and Data and credits sections. The map's height is the window less the measured part of the page above it and the clock row (`dvh`, 420px floor, 1500px ceiling); gutters are `clamp(16px, 2.2vw, 48px)` and the tool is capped at 2500px. Under 900px the controls stack above the map; on a phone (narrow, or on its side) the panels stay over the map in full screen as before. Compact view (button or the C key, not while typing; remembered for the session) hides the column. The full credits live in the "Data and credits" section; the map keeps a short line that links to it.
