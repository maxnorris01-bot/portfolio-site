## 1. What is gated
Every colour menu that exists (the brief says "Text colour"; the page's button is named `Font colour`, then `Shape Fill` and `Shape Outline`) keeps what it has (Page colours, Standard colours, the "No fill" or "No outline" item, More colours… with the hex box, Gradient and Weight and Dashes where they are) and gains, after Standard colours and in this order: the **Colour grid**, **Recent colours** (only when there is one) and **Pick any colour…**. Gradient From and To are not changed (a stated limit). Nothing is stored. The colour input of the picker sits beside the menu button (the menu closes when an item is chosen, so an input inside it would be gone before `change`), and the item opens it with `showPicker()` (`click()` if that fails).

## 3. Recent colours and the picker (the rules the specs check)
Recent colours: the last 8 colours applied through the three menus, newest first, no duplicates (applying one again moves it to the front), six-digit lower-case hex (the hex box takes `#rgb` and records `#rrggbb`), each named `Recent #rrggbb`; recorded when applied by a swatch (page or standard), a grid cell, a recent, the hex box or the picker; not by No fill, No outline or Undo; one list for the three menus; in memory only (no localStorage, no sessionStorage, no cookie), so a load of the page empties it. The picker applies one edit when the input says `change` and none for `input` events alone or when it is cancelled.

**A1. Where the colour input is (found by the first run of the earlier specs on the built page, before the final run; no spec was scored).** The locked text says the input sits "beside the menu button". Put in the ribbon it is one more `input` of `[data-ribbon]`, and the earlier locked checks that count and measure the ribbon's controls (W02, W03, W08, T15, T16, U03, U08, U09, U12, R16, V09, Y14) failed on it. The input is therefore drawn in `<body>`, outside the ribbon and outside the menu: it stays mounted when the menu closes (which is what the rule was for), is never seen (opacity 0, 1 px, `aria-hidden`, out of the tab order) and, when the item is chosen, is put under its button so the browser's popup opens there. The specs find it by `input[type=color][data-picker=<button name>]` in the whole document; "next to the button" in `pickerFire` and `pickerPresent` is read that way. Nothing else changes.
