## What changed
- **Colour grid:** `colourGrid()` in `menus.ts` (60 values; the locked table is in `docs/ui-editor-gate-rules-round7b.md` section 2 and a unit test compares the two). **Source of the 60 values:** the CSS Color HSL to RGB conversion applied to the brief's recipe (row 1 greys at lightness 100, 95, 85, 75, 50, 35, 25, 15, 5, 0; rows 2 to 6 saturation 70, lightness 30, 45, 60, 75, 88 at hues 0, 28, 50, 90, 140, 175, 215, 245, 280, 330), channels rounded half up, six-digit lower-case hex; first generated by a script (`grid.py` in the session's scratch folder, a Python copy of the formula) for the locked table, and the page computes them with the same formula in TypeScript; all 60 differ.
- **Recent colours:** `recents.ts`, a small in-memory store (no localStorage, no cookie); the last 8, newest first, no duplicates; recorded for a page or standard swatch, a grid cell, a recent, the hex box (as six digits) and the picker; not for No fill, No outline or Undo.
- **Pick any colour…:** closes the menu and opens the browser's colour picker (`showPicker()`, `click()` as the fallback); one edit on the input's `change`, none for `input` events or a cancel. The input is in `<body>` (amendment A1).
- **Layout:** 20 px cells ten to a row; below 1048 px 44 px cells wrapping to as many as fit (8 at 1000 px, 7 at 390).
